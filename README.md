# Forma — Studio parametrico

Editor CAD 2D per schizzi parametrici, con vincoli, quote, ripetizioni e regole condizionali. Esporta DXF, AutoLISP e fogli Excel con il pulsante **Crea DXF**.

Il foglio **Excel → DXF** richiede Excel desktop per Windows, macro abilitate e Node.js LTS installato sul PC. Le quote si aggiornano quando modifichi i parametri. **Crea DXF** salva il disegno nella cartella scelta.

[Apri Forma](https://pegosauro.github.io/Forma/). Per installarla, usa il menu del browser in Edge o Chrome. In Safari su iPhone apri **Condividi → Aggiungi alla schermata Home**.

Dopo il primo avvio online, l'editor è disponibile anche offline. L'app salva il progetto corrente nel browser. Per trasferire un progetto o tenerne una copia, usa **Salva progetto** in Forma.

GitHub Pages pubblica dalla radice del ramo `main`. Per un aggiornamento che modifica i file dell'app, aggiorna anche la versione della cache in `sw.js`.
